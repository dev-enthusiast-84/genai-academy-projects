Week 1 case study

Subscription Reality Check

A Streamlit data app for understanding recurring subscription costs, measuring cost per use, and testing cancellation savings scenarios.

Open live app View code
Problem Brainstorming Tech stack Repo structure Design choices Links

Problem statement

Losing track of recurring subscriptions and actual usage.

The project started from a personal daily-life problem: signing up for new products, tools, and trials when they seem useful, then forgetting to cancel subscriptions later.

The app answers a simple question: what happens to yearly spending if selected subscriptions are removed?

Approaches brainstormed

From broad ideas to one focused data workflow.

Explored

Real-world Week 1 ideas such as fridge waste tracking, subscription tracking, time-use analysis, takeout spending, chores, and shared expenses.

First direction

A shared expense splitter was considered because it had useful calculation logic, but it felt less personally relevant.

Final direction

Subscription Reality Check was selected because it matched a user-provided problem: adding subscriptions when interested in a new product and later missing cancellations.

Scoped workflow

The app was narrowed to monthly cost, usage, cost per use, category spending, and a savings scenario selector.

Technology stack

Python data app with testable business logic.

Python Streamlit Pandas Altair Pytest CSV GitHub Pages Streamlit Community Cloud

Streamlit powers the interactive app. Pandas handles tabular data. Altair renders readable charts. Pytest validates calculation logic separately from the UI.

Design choices

A personal finance cockpit with clear actions.

The app uses a light paper-like background, dark ink text, green savings accents, and coral risk highlights. These choices were discussed while refining the Streamlit interface for readability.

During implementation, several visible UI issues were refined: tab labels, button text, chart axis labels, chart background contrast, and generic chart toolbars. The final interface keeps explicit user actions such as downloading current data and exporting a cancellation action plan.

Week 1

Subscription Reality Check

A Streamlit app for tracking recurring subscriptions, calculating cost per use, reviewing category spend, and simulating yearly savings by removing selected subscriptions.

Personal problem

The app is based on losing track of subscriptions after signing up for new tools, trials, and services.

Data workflow

It loads a CSV, validates columns, calculates spend metrics, ranks risk, and exports a cancellation action plan.

Code-heavy logic

Core logic is separated into testable Python functions for scoring, cost per use, category totals, and savings scenarios.

🤖 Three-Agent System

Strategist Agent

  • Analyzes new content
  • Searches similar posts
  • Identifies patterns
  • Recommends action
  • Provides confidence score

Creator Agent

  • Generates draft content
  • Uses voice samples
  • Platform-optimized
  • Style consistent
  • Maintains user voice

Reviewer Agent

  • Quality scores draft
  • Checks tone & clarity
  • Detects generic phrases
  • Suggests improvements
  • Validates brand fit

💾 Data Flow: Semantic Search Example

User content: "AI in product development" ↓ [1] Generate embedding (OpenAI API) ↓ → 1536-dimensional vector [2] Query Pinecone ↓ → Top 5 similar posts (cosine similarity) [3] Fetch metrics from PostgreSQL ↓ → impressions, reactions, engagement rates [4] Identify patterns ↓ → "Deep-dives avg 14% engagement" [5] LLM processes patterns + context ↓ Strategist Recommendation: "Repurpose as LinkedIn thread"

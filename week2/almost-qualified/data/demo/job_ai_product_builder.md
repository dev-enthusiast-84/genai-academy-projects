# Job description: AI Product Builder Intern

Document category: job

## Requirements

- Build small AI-powered web apps that turn ambiguous user problems into clear workflows.
- Use Python and Streamlit or a similar lightweight app framework.
- Work with structured data, validation, and clear user-facing outputs.
- Explain technical choices in README files and demo materials.
- Use retrieval augmented generation or vector search to ground model answers.
- Deploy prototypes to a shareable cloud environment.
- Communicate limitations honestly when evidence is incomplete.

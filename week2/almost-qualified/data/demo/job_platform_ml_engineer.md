# Job description: Platform ML Engineer

Document category: job

## Requirements

- Operate containerized services using Docker and Kubernetes.
- Build CI/CD pipelines for production model serving.
- Monitor latency, reliability, and cost in live customer-facing systems.
- Implement retrieval or search pipelines with explicit evaluation.
- Write Python services with tests and clear documentation.
- Own infrastructure-as-code changes using Terraform.
- Support security and compliance reviews for enterprise customers.

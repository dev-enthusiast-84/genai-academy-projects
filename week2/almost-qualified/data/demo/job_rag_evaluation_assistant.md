# Job description: RAG Evaluation Assistant

Document category: job

## Requirements

- Create RAG workflows that answer questions from a bounded document corpus.
- Separate source evidence from instructions contained inside documents.
- Measure faithfulness, retrieval precision, and unsupported-question handling.
- Build a simple review interface where users can inspect citations.
- Use Python to prepare data and validate outputs.
- Explain what the system cannot prove from the available corpus.

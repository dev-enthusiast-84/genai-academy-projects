## GitHub Pages Showcase

This repository includes a static showcase site in [`docs/`](docs/). To publish it with GitHub Pages:

1. Open the repository on GitHub.
2. Go to `Settings` > `Pages`.
3. Set `Source` to `Deploy from a branch`.
4. Select branch `main` and folder `/docs`.
5. Save.

The site will publish at:

```text
https://dev-enthusiast-84.github.io/genai-academy-projects/
```

The showcase home page links to a Week 1 case study page with the problem statement, brainstormed approaches, technology stack, implemented repo structure, design choices, and live app URL. Unknown values, such as submission document links that have not been provided yet, stay marked as pending.

## Week 1

**Subscription Reality Check** is a Streamlit data app that helps users review recurring subscription spending, calculate cost per use, compare spending by category, and simulate yearly savings by removing selected subscriptions.

Main app path for Streamlit Community Cloud:

```text
week1/subscription-reality-check/app.py
```
